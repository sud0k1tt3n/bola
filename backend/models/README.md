# Веса модели

Положите сюда `best.pt` — YOLO11n, дообученную на классы
`flooding`, `bridge_collapse`, `fallen_tree` (`python train.py train ...` копирует его сюда сам).

Файла-заглушки здесь намеренно нет: пустой или фиктивный `best.pt` уронил бы загрузку.
Пока файла нет, backend работает на COCO-весах `yolo11n.pt` (скачиваются автоматически)
с классами-заглушками, либо в режиме `mock`, если ultralytics не установлен.
