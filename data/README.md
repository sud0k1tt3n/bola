нарисованные поле, дорога, вода. Нужны для проверки EXIF-парсинга, геопривязки и
сквозного прогона API, а не для оценки нейросети.

## Датасет для обучения (план)
Готовый датасет из экспорта CVAT лежит в `hazards/` (делает `backend/prepare_dataset.py`, см.
[docs/TRAINING.md](../docs/TRAINING.md)): `images/{train,val}`, `labels/{train,val}`, `hazards.yaml`,
классы `0 flooding, 1 bridge_collapse, 2 fallen_tree`.

Кандидаты в источники (лицензии проверить перед использованием):
* **FloodNet** — аэроснимки БАС после урагана Харви, семантическая сегментация, есть
  класс «затопленная дорога». Маски → bbox по связным компонентам.
* **RescueNet** — аэроснимки БАС после урагана Майкл, есть классы повреждений и
  «заблокированная дорога» (часто — упавшие деревья).
* **Собственные полёты** — обязательно: сезонность, типичные для РФ дороги и переправы,
  зимние/весенние условия (паводок).
* **bridge_collapse** — публичных аэроданных почти нет. Варианты: собственная съёмка,
  архивные фото МЧС/СМИ (права!), синтетика (вставка повреждений на снимки целых мостов),
  на первом этапе — оценивать класс отдельно и не обещать метрик.

Рекомендации по разметке: делить train/val/test **по полётам**, а не по кадрам (соседние
кадры почти одинаковы → завышенные метрики); добавлять «трудные негативы» — реки и пруды
без подтопления дорог, лежащие брёвна на обочине, целые мосты.
